TCP: establish, acknowledge, recover

Connection setupDirectionPurpose
SYNClient → serverStart a connection; announce an initial sequence number
SYN + ACKServer → clientAcknowledge the client; announce the server’s sequence number
ACKClient → serverAcknowledge the server
  • Sequence numbers identify positions in the byte stream.
  • Acknowledgments and retransmission let TCP recover from loss.
  • A connection uses both IP addresses and both transport ports.
TCP does not encrypt traffic. A successful handshake does not prove an application request will succeed.
