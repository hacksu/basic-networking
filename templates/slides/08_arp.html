ARP: from an IPv4 address to a MAC

1 · Ask locally

A broadcasts: “Who has 192.168.50.20?”

Ethernet destination:
ff:ff:ff:ff:ff:ff

2 · B replies

B supplies its MAC address, normally in a unicast reply to A.

A caches the IP → MAC mapping.

3 · Send the data

A can address an Ethernet frame to B’s MAC.

The IP packet still targets 192.168.50.20.

Host ARP cache: IP → MAC. Switch forwarding table: MAC + VLAN → port. They solve different problems.
