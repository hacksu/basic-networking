DNS: a name is not a route

Application asks
for a name
→
Local cache /
DNS resolver
→
DNS records
A / AAAA

Resolve the name

A records supply IPv4 addresses; AAAA records supply IPv6 addresses.

Cached answers can be reused until their TTL expires.

Then connect

The host still needs a route and next-hop delivery.

The transport connection and application request can fail separately.

DHCP configures the host. DNS resolves names. Neither guarantees that a website will load.
